# サービス設定デフォルト設定一覧

サービス設定のデフォルトを以下の通りに設定されていること。
ただし、変更が必要になれば、ユーザーが設定を変更できるようにすること。
また、サービス設定を追加・削除もできるようにすること。
また、以下のサービスを選択するだけでなく、身体介護or生活援助を選択し時間を指定できるようにすること（生活援助65分など）

|サービス設定名|種類|時間|備考|
|---|---|---|---|
|身体0|身体介護|20分||
|身体1|身体介護|30分||
|身体2|身体介護|60分||
|生活2|生活援助|45分||
|生活3|生活援助|60分||
