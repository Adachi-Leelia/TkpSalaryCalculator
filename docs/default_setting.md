# 初期サービス設定定義

## 1. 目的

初回利用時の入力負担を減らすため、サービス種類、時間区分および入力補助用のサービス設定を初期候補として提供する。本書の初期値は給与単価を規定するものではなく、利用者が勤務先の給与体系に合わせて確認・変更する。

## 2. 用語と初期値

- `サービス種類`は給与単価を分類する単位とする。
- `時間区分`はサービス種類に属する標準所要時間とする。
- `サービス設定`は、勤務入力時にサービス種類と標準時間をまとめて選ぶための入力補助とする。給与計算の正本ではない。

| サービス設定名 | サービス種類 | 時間区分 | 標準時間 | 初期状態 |
| --- | --- | --- | ---: | --- |
| 身体0 | 身体介護 | 身体0 | 20分 | 使用中 |
| 身体1 | 身体介護 | 身体1 | 30分 | 使用中 |
| 身体2 | 身体介護 | 身体2 | 60分 | 使用中 |
| 生活2 | 生活援助 | 生活2 | 45分 | 使用中 |
| 生活3 | 生活援助 | 生活3 | 60分 | 使用中 |

## 3. 初回設定時の扱い

- 基本単価は勤務先によって異なるため初期金額を設けず、利用者が使用するサービスにだけ入力する。
- 単価方式の初期値は時給方式とする。
- 利用者は初期候補を編集、追加、並べ替えおよび無効化できる。
- 使用しない初期候補は無効化でき、初回設定の完了条件には含めない。
- 物理削除は、その論理IDを勤務記録、基本シフトまたは設定スナップショットが参照していない場合だけ許可する。参照済みの場合は無効化する。
- 登録済みのサービス設定を選ばず、`身体介護・65分`や`生活援助・任意時間`のようにサービス種類と勤務時間を直接指定できる。

## 4. 変更の影響

サービス設定は入力値をコピーするための現在値テンプレートである。後から名称や標準時間を変更または無効化しても、作成済みの勤務記録は変更しない。

サービス種類、時間区分および単価の年月別変更は、[設定履歴データモデル](setting_history_data_model.md)に従う。
